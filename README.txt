STATEMENT STUDIO - LOCAL APPLICATION

Double-click Start Statement Studio.cmd (or Statement Studio.html).
This is the permanent application folder. No installation or internet connection is needed for statement preparation.
Future updates can replace Statement Studio.html in this same folder; keep its name and location unchanged.

FOLDERS
Backups: save company JSON backups here.
Reports: save generated PDFs here.
Source: editable application source and bundled libraries.

ONE-TIME TRANSFER OF EXISTING COMPANIES
The earlier application remains at:
C:\Users\dell\Documents\Codex\2026-09-10\can-x20\outputs\Hoistx-Statement-Builder.html
Company data is in browser storage and may not follow an HTML file to a different location.
1. In the earlier application, open each company and choose Download backup.
2. Save those JSON files in this folder's Backups folder.
3. Open this permanent application in the same browser you intend to use regularly.
4. Create a separate company for each backup, then choose Open backup in that company's workspace.
5. Check the restored company before proceeding to the next one.

DATA STORAGE
Company edits are still saved in browser storage. Backups and reports are saved to disk only when you download them. These folders do not enable automatic disk saving. Choose the Backups or Reports folder in the browser's save dialog; otherwise files may go to Downloads.
Use the same browser/profile each time and retain regular backups.
